PROJECT NOTES

RISC-V Processor Verification Toolkit

A Python verification core with a web interface for running and examining differential tests.

PURPOSE-BUILT VERIFICATION

One engine. Two ways to use it.

The CLI and dashboard both call the same Python runner. The web layer handles requests, job status, and presentation; instruction generation, simulation, reference execution, comparison, and coverage remain in the existing verification modules.

⌘

RISC-V and ISA

RISC-V is an open instruction-set architecture. An ISA defines the instructions and architectural behavior software can rely on. This project implements a small RV32I subset.

▹

Simulator and oracle

The simulator executes instructions. A separately written reference model calculates expected architectural behavior. Both begin from cloned register, PC, and memory state.

⇄

Differential testing

The comparator checks registers, PC, and memory after execution. A seed and one-based test ID let the same generated program be replayed.

◔

Instruction coverage

Mnemonic coverage counts supported instructions that actually executed at least once. It measures test exercise, not correctness or exhaustive verification.
